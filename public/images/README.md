# /public/images — Photo Guide

Drop your photos here and they'll automatically show on the site.

## Expected filenames

| File | Where it appears | Notes |
|------|-----------------|-------|
| `payton.jpg` | Hero section (right side) | Any photo, color |
| `payton-bw.jpg` | Connect/contact page | Will be rendered in grayscale — can be same as above |
| `about.jpg` | About section (right side) | Lifestyle / candid |
| `generosity.jpg` | Generosity section | Uganda project / Epiphany Global |

## How to add photos

**Option A — Send via Telegram:**
Just send the photo to Mr. Wallace in Telegram and say which slot it's for.
I'll save it to this folder with the right filename.

**Option B — Drop directly:**
Drag any photo into `C:\Users\payto\Documents\personalwebsite\public\images\`
and rename it to one of the filenames above.

## Tips
- JPG or PNG both work
- Portraits: roughly 3:4 ratio looks best
- No minimum size but 800px wide+ is ideal for crispness
- The B&W headshot for Connect will be auto-converted to grayscale in CSS —
  no need to pre-process it, just send a regular photo
